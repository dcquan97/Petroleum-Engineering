# Petroleum Engineering at UD–DUT — Demo Website

Demo microsite for the **Petroleum Engineering** programme at the **University of Danang – University of Science and Technology (UD–DUT)**.

Built from the project proposal deck *"Website Kỹ thuật Dầu khí – ĐH Bách khoa Đà Nẵng"* (V2, 11/2026).

## Purpose

This is a **static HTML demo** of a proposed English-language microsite to be hosted inside the official UD–DUT ecosystem (canonical: `en.dut.udn.vn/petroleum-engineering/`). It supports the QS World University Rankings by Subject (Engineering — Petroleum) evidence strategy.

## Sections

- **Hero** — positioning & key stats
- **QS indicators** — 5 indicators the website must make visible (AR 40%, ER 30%, Citations 15%, H-index 15%, IRN)
- **Programme pillars** — process design, refining & gas, simulation, piping/corrosion, HSE, hydrogen & renewables
- **Evidence layers** — 5 content layers + accessibility support layer
- **Research** — publications, verified links, trends, H-index
- **Sitemap** — 8 proposed content clusters
- **Audiences** — scholars, universities, industry, students/alumni
- **Roadmap** — 10-week implementation plan

## Run locally

Open `index.html` in any browser — no build step required.
